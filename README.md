# 🎮 Uzbekcha O‘yin

Assalomu alaykum! Ushbu repozitoriyga **o‘zbek tilidagi qiziqarli o‘yin** loyihasi joylangan. 

## 📖 O‘yin haqida
Bu o‘yin bo‘sh vaqtni maroqli o‘tkazish uchun yaratilgan. Oddiy boshqaruv va qiziqarli jarayon sizni zeriktirmaydi!

## 🕹 Qanday o‘ynaladi?
* **Boshlash:** Yashil bayroqcha (yoki *Start* tugmasi) orqali o‘yinni ishga tushiring.
* **Boshqaruv:** Klaviatura strelkalari (`⬆️`, `⬇️`, `⬅️`, `➡️`) yoki sichqoncha yordamida qahramonni boshqaring.
* **Maqsad:** To‘siqlardan o‘tib, eng yuqori ball to‘plash.
